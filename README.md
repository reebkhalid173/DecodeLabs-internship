## Project Description

**NexaStudio** is a fully static, professional web presence for a fictional digital design and development agency. The site demonstrates mastery of Information Architecture, Semantic HTML5, and CSS3 layout systems — the three pillars emphasised in the DecodeLabs Project 1 brief.

Every line of markup is intentional. Every styling decision traces back to an external stylesheet. No JavaScript, no frameworks, no inline styles. Just structure and presentation, cleanly separated.

---

## Features

| Category | Detail |
|---|---|
| **Semantic HTML5** | `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`, `<address>`, `<blockquote>` — no div soup |
| **Heading hierarchy** | One `<h1>` per page; `<h2>` per section; `<h3>` for cards |
| **External CSS only** | Zero inline or internal styles; single `style.css` source of truth |
| **DRY / BEM-inspired** | CSS custom properties (design tokens); block-element naming; reusable utilities |
| **Layout systems** | CSS Grid for page structure; Flexbox for component alignment |
| **Responsive design** | Mobile-first media queries at 400 px, 768 px, and 1024 px |
| **CSS-only mobile nav** | Hamburger toggle via `<input type="checkbox">` — zero JavaScript |
| **Accessibility** | `:focus-visible` ring; ARIA labels; landmark roles; `alt` on every image; `prefers-reduced-motion` |
| **Image best practices** | Explicit `width`/`height` (prevents CLS); `loading="lazy"` on below-fold images |

### Sections included

1. Header + Sticky Navigation Bar  
2. Hero (headline, sub-copy, CTA buttons, stats bar)  
3. About (two-column image + copy)  
4. Services (3-column card grid)  
5. Features (browser mockup + Quality Gate checklist)  
6. Portfolio / Gallery (asymmetric CSS Grid)  
7. Testimonials (3-column with accent variant)  
8. Contact (split layout + accessible form)  
9. Footer (4-column grid + bottom bar)

## Technologies Used

| Technology | Purpose |
|---|---|
| HTML5 | Page structure and semantic markup |
| CSS3 | All visual presentation |
| CSS Custom Properties | Design token system (colours, spacing, type) |
| CSS Grid | Macro page layout |
| CSS Flexbox | Component-level alignment |
| CSS Media Queries | Responsive breakpoints |
| Google Fonts | `Syne` (display) + `Inter` (body) |

**Not used:** JavaScript · Bootstrap · Tailwind · React · Vue · any framework or library.
